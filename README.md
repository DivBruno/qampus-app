## Sobre o Projeto
Projeto para implementação de um sistema web com foco em fórum acadêmico, desenvolvido para a disciplina de Engenharia de Software ministrada pela Professora [Thaís Burity](https://github.com/taburity), da UFAPE, com o intuito de avaliação.

O sistema tem como objetivo oferecer uma plataforma onde alunos possam, de forma rápida e prática, publicar dúvidas, responder perguntas e compartilhar conhecimento. Além disso, professores poderão utilizar o ambiente para esclarecer questões, divulgar eventos, projetos e comunicados acadêmicos.

A proposta busca centralizar a comunicação acadêmica em um único ambiente, promovendo uma melhor organização das informações e incentivando a colaboração entre alunos e professores, tornando o processo de aprendizagem mais acessível e eficiente.

## Objetivos
- Permitir que usuários realizem cadastro na plataforma, informando dados básicos como nome, e-mail e senha.
- Possibilitar que alunos publiquem dúvidas, editem suas postagens e interajam por meio de respostas.
- Permitir a visualização de perguntas já existentes, facilitando o acesso a soluções e discussões relevantes.
- Incentivar o compartilhamento de conhecimento entre alunos e professores.
- Permitir que professores respondam dúvidas e publiquem anúncios de eventos, projetos e comunicados acadêmicos.
- Implementar um sistema de votação em perguntas e respostas, permitindo avaliações positivas e negativas.
- Destacar conteúdos mais relevantes com base na interação dos usuários.
- Organizar as informações de forma clara, permitindo que os usuários acompanhem suas interações e encontrem conteúdos com facilidade.

## Instrução de instalação
### Frontend
```bash
# Acesse a pasta do frontend
cd frontend\frontend-qampus-app

# Instale as dependências
npm install

# Execute o projeto
ng serve

O frontend estará disponível em:

http://localhost:4200
```
### Backend
```bash
# Acesse a pasta do backend
cd backend\backend-qampus-app

# Execute a aplicação
QampusApplication.java

O backend estará disponível em:

http://localhost:8080
```
